Contribute

OBM2 Pro is an open-source project. Contributions of all kinds are welcome — code, documentation, screenshots, and community support.

Code

Fork the repository on GitHub, create a feature branch, and open a pull request:

git clone https://github.com/ObM2/ObM2Pro.git
cd ObM2Pro
git checkout -b feature/my-improvement
# ... make changes ...
git push origin feature/my-improvement

Then open a Pull Request from your fork to ObM2/ObM2Pro. Please include a clear description of what the change does and why.

💡

Check existing issues on GitHub before starting a large feature — it may already be in progress or there may be design guidance to follow.

Documentation

The documentation site lives in the ObM2/obm2.github.io repository as plain HTML files in the docs/ folder.

To improve a page: fork the repo, edit the HTML directly, and open a PR. No build step required — the site is pure HTML/CSS/JS.

FileWhat it covers
docs/stacker.htmlAll blocks — most likely to need updates
docs/variables.htmlVariable system and BotData
docs/loliscript.htmlLanguage reference
docs/usage.htmlRunner, proxy, config manager
docs/examples.htmlReal-world examples

Screenshots

Many pages currently show placeholder boxes where real screenshots of the M2 Pro interface should appear. If you have a working installation of OBM2 Pro, you can contribute screenshots:

  1. Take a screenshot of the relevant block or page in OBM2 Pro
  2. Save it as a .jpg or .png in assets/img/ss/
  3. Replace the <div class="screenshot-placeholder"> in the relevant HTML file with <img class="screenshot-real" src="../image/your-file.jpg" alt="Description"/>
  4. Open a PR
ℹ

Screenshots should show the dark M2 Pro theme. Crop to the relevant block or panel — full-window screenshots are too large to be useful inline.

Share

Help grow the community by sharing OBM2 Pro with others who do web testing and automation. Link to the documentation, share example configs, or write tutorials.
