Remote API

The Remote API is a separate ASP.NET Core service that exposes OBM2 Pro functionality over HTTP, enabling integration with external tools and remote runner management.

About

The Remote API runs as a standalone process alongside OBM2 Pro. It provides endpoints for starting/stopping runners, querying hit statistics, and managing configs and proxies remotely.

⚠

The Remote API should only be exposed on a trusted network or behind a reverse proxy with TLS. Never expose it directly to the public internet without additional access controls.

Setup & Configuration

Configuration is stored in appsettings.json next to the API executable:

{
  "ConnectionStrings": {
    "DefaultConnection": "Filename=hits.db"
  },
  "configFolder": "C:\\OBM2\\Configs",
  "secretKey": "your-secret-key-here",
  "Logging": {
    "LogLevel": {
      "Default": "Warning"
    }
  }
}
KeyDescription
DefaultConnectionPath to the LiteDB hits database
configFolderDirectory containing .loli config files
secretKeyShared secret for JWT authentication (change this!)

Running the API

dotnet ./OpenBulletAPI.dll --urls "http://0.0.0.0:5000"

The admin panel is then accessible at http://<host>:5000/admin. The default port is 5000. Configure a different port in Settings → Remote → Port.

Authentication

The API uses JWT bearer token authentication. Obtain a token by POSTing credentials to /api/auth/login:

POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "your-password"
}

# Response:
{
  "token": "eyJhbGci..."
}

Include the token in subsequent requests as a Bearer header:

Authorization: Bearer eyJhbGci...

Key Endpoints

MethodPathDescription
POST/api/auth/loginObtain JWT token
GET/api/configsList available configs
GET/api/hitsQuery hits with filters
POST/api/runner/startStart a runner with a config and wordlist
POST/api/runner/stopStop the running runner
GET/api/runner/statusGet runner progress and statistics
GET/api/proxiesList loaded proxies
POST/api/proxiesUpload a new proxy list
ℹ

Hit exports via the API return a ZIP archive containing a plain-text file. The format matches the export format configured in Settings.
