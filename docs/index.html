What is OBM2 Pro?

OBM2 Pro is a fork of the original OpenBullet project, redesigned with a modern dark UI, new protocol blocks (TLS, IMAP, POP3, SMTP, FTP), an improved Stacker with dynamic variable suggestions, and many quality-of-life improvements for automation professionals.

Architecture Overview

Scripts are written in LoliScript — a line-based domain-specific language — or assembled visually in the Stacker drag-and-drop editor. Each block corresponds to a LoliScript keyword and exposes typed output variables accessible by all subsequent blocks via <varName> syntax.

ℹ

All blocks store their output in BotData, which is the shared state object for a single bot execution. Variables persist across blocks within the same run.
