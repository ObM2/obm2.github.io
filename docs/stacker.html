Stacker & Blocks

The Stacker is the visual editor for building LoliScript configs. Each block represents one logical operation. Blocks execute in order and share state via BotData variables.

Overview

Add blocks by clicking Add Block in the Stacker toolbar. Use the search box to filter by name. Blocks can be dragged to reorder them.

Each block produces output variables referenced as <varName>. Variables defined by previous blocks appear in combo-box dropdowns throughout the UI as you work.

ℹ

The Stacker and the LoliScript text editor stay in sync. You can switch between views at any time without losing data.

HTTP Request Block

Sends HTTP/HTTPS requests and captures the response into BotData variables.

Request Settings

FieldDescription
MethodGET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS
URLTarget URL. Supports variable substitution: https://example.com/<username>
Content-TypeBody encoding: application/x-www-form-urlencoded, application/json, multipart/form-data, text/plain
Post BodyRequest body. For multipart, use name=value pairs separated by newlines.
Cookie JarEnable to persist cookies across requests within the same bot run.
Follow RedirectsAutomatically follow HTTP 3xx redirects.
Read Response BodyDecode the response body as UTF-8 text into <SOURCE>.

Custom Headers

Add one header per line in the format Header-Name: value. Variable substitution is supported in values.

User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept-Language: en-US,en;q=0.9
X-Custom-Token: <token>

Output Variables

VariableTypeContent
<SOURCE>SingleResponse body as UTF-8 text
<RESPONSECODE>SingleHTTP status code, e.g. 200
<ADDRESS>SingleFinal URL after redirects
<HEADERS(*)>SingleAll response headers as a string
<HEADERS{name}>SingleSpecific response header by name
<COOKIES(*)>SingleAll cookies as a string
<COOKIES{name}>SingleSpecific cookie by name
<ERROR>SingleException message if the request throws an error

LoliScript Example

REQUEST GET "https://example.com/login"
REQUEST POST "https://example.com/api/login" CONTENT-TYPE:"application/json" POSTDATA:"{\"user\":\"<user>\",\"pass\":\"<pass>\"}"

TLS Request Block

Sends requests through a local TLS proxy for native TLS fingerprint control, bypassing bot-detection systems that check JA3/JA4 signatures.
ℹ

TLS Proxy is a companion process (tls-proxy.exe) that starts automatically with OBM2 Pro. Its status is shown as a real-time badge in the block UI. If the proxy is unreachable, the request falls back to the ExtremeNet engine.

Settings

FieldDescription
Method / URL / BodySame as HTTP Request block
TLS ProfileFingerprint to impersonate: Chrome, Firefox, Safari, Random
TLS Proxy PortPort the TLS proxy listens on. Default: 8080. Must match Settings → Proxy → TLS Proxy Port.
Custom HeadersSame format as HTTP Request

Proxy Status Badge

The block header shows a live badge:

StateMeaning
Checking…Initial probe in progress
Active (Xms)Proxy reachable, round-trip latency shown
UnreachableProxy process not running or wrong port — fallback to ExtremeNet
DisabledTLS proxy disabled in settings

Output Variables

Identical to the HTTP Request block: <SOURCE>, <RESPONSECODE>, <ADDRESS>, <HEADERS(*)>, <COOKIES(*)>, <ERROR>.

LoliScript Example

TLSREQUEST GET "https://target.com/api/check" TLSPROFILE:"Chrome"
TLSREQUEST POST "https://target.com/api/login" TLSPROFILE:"Random" CONTENT-TYPE:"application/json" POSTDATA:"{\"email\":\"<email>\",\"password\":\"<pass>\"}"

Keycheck Block

Evaluates conditions against BotData variables to set the bot's final status.

The Keycheck block contains one or more Keychains. A keychain defines a target status and a logical mode (OR / AND), and holds one or more Keys (conditions). If all conditions in a keychain are satisfied, the bot status is set and the script stops.

Bot Statuses

Available target statuses: SUCCESS, FAILURE, BAN, RETRY, CUSTOM.

Key Operators

OperatorCondition
ContainsLeft term contains the right term string
DoesNotContainLeft term does not contain the right term
ExistsLeft term is non-empty
DoesNotExistLeft term is empty or null
EqualToExact string match
NotEqualToString does not match
GreaterThanNumeric comparison (>)
LessThanNumeric comparison (<)
MatchesRegexLeft term matches a .NET regex pattern

Left Term — Available Sources

The left term (source) combo-box shows all available variables. Default fields always present:

<SOURCE> <HEADERS(*)> <HEADERS{*}> <COOKIES(*)> <COOKIES{*}> <RESPONSECODE> <ADDRESS> <ERROR>

All variables produced by blocks above the Keycheck in the stacker are also available and update dynamically as you add or remove blocks.

💡

<ERROR> is set automatically when any block throws an exception. Email protocol blocks (IMAP, POP3, SMTP, FTP) do not stop the script on error — instead they write the exception message to <ERROR> and continue, so the Keycheck can classify the result.

LoliScript Example

IMAP Connect "imap.gmail.com" "993" (UseSSL=True) 30000
IMAP Login "<email>" "<pass>"
IMAP SearchMails "UNSEEN" "unreadCount"
KEYCHECK
  KEYCHAIN Success OR
    KEY "<unreadCount>" GreaterThan "0"
  KEYCHAIN Failure OR
    KEY "<ERROR>" Contains "Authentication failed"
  KEYCHAIN Ban OR
    KEY "<ERROR>" Contains "Too many connections"

Parse Block

Extracts data from a variable using LR anchors, CSS selectors, JSONPath, or Regex.

Parse Modes

LR CSS JSON REGEX
ModeDescriptionKey Fields
LRExtract text between a left and right anchor stringLeft anchor, Right anchor
CSSSelect HTML element with a CSS selector, then get an attribute or inner textCSS Selector, Attribute
JSONExtract a value from JSON using dot-notation pathJSON Path (e.g. data.user.token)
REGEXExtract a capture group from a .NET regex patternPattern, Group index

Output Types

TypeDescription
SingleFirst match stored as a scalar string variable
ListAll matches stored as a list variable, accessed via <VAR[0]>, <VAR[*]>

Source Variable

The dropdown shows all variables available from blocks above this one, plus the 8 defaults (<SOURCE>, <ERROR>, etc.).

LoliScript Example

PARSE <SOURCE> LR "token\":\"" "\"" -> "authToken"
PARSE <SOURCE> JSON "user.email" -> "userEmail"
PARSE <SOURCE> CSS "#user-list li" ATTRIBUTE:"innerText" LIST -> "userList"
PARSE <SOURCE> REGEX "(\d{4}-\d{4}-\d{4})" GROUP:1 -> "cardNumber"

The Input String field is a combo-box: type any literal value or pick a variable from the dropdown. It supports all variables available from blocks above.

When the input is a list variable and the function supports it, use <LIST[*]> to apply the function to every element.

IMAP Block

Read and manage email via IMAP. Session persists across blocks in the same bot run.
ℹ

IMAP errors do not stop the script. Instead the exception message is written to <ERROR> and execution continues. Use a Keycheck immediately after to classify the result.

Commands

CommandParametersOutputNotes
Connect host, port, useSSL, timeout (ms) — Default timeout: 30000 ms
Login email, password —
SearchMails query (IMAP search criteria), variableName Single — match count e.g. UNSEEN, FROM "noreply@example.com"
ReadMail index (0-based), variableName Single — mail body Reads from results of last SearchMails
GetMailCount variableName Single — total in folder
GetLastMessageId variableName Single — UID
ListFolders variableName List — folder names
DeleteMail index (0-based) — Deletes from last SearchMails results
MoveToFolder index, folderName —
Logout — — Graceful logout
Disconnect — — Closes TCP connection

LoliScript Example — Email Verification Check

IMAP Connect "imap.gmail.com" "993" (UseSSL=True) 30000
IMAP Login "<email>" "<pass>"
IMAP SearchMails "FROM \"verify@service.com\"" "mailCount"
IMAP ReadMail 0 "mailBody"
PARSE <mailBody> REGEX "code=([A-Z0-9]{6})" GROUP:1 -> "verifyCode"
IMAP Logout
IMAP Disconnect
KEYCHECK
  KEYCHAIN Success OR
    KEY "<verifyCode>" Exists
  KEYCHAIN Failure OR
    KEY "<ERROR>" Contains "Authentication"

Library

Uses MailKit 4.17.0 on .NET 8. Older versions (<4.x) have known security vulnerabilities — do not downgrade.

FTP Block

Transfer files and list directories via FTP/FTPS. Powered by FluentFTP 54.1.1.

Commands

CommandParametersOutput
Connect host, port, user, password, useSSL, timeout (ms) —
ListFiles remotePath, variableName List — file paths
Download remotePath, localPath, variableName Single — "OK" / "Failed"
Upload localPath, remotePath, variableName Single — "OK" / "Failed"
DeleteFile remotePath —
FileExists remotePath, variableName Single — "True" / "False"
Disconnect — —

Default timeout: 15000 ms (applied to both connect and read operations).

LoliScript Example

FTP Connect "ftp.example.com" "21" "<user>" "<pass>" (UseSSL=False) 15000
FTP ListFiles "/public" "fileList"
FTP FileExists "/private/secret.txt" "exists"
FTP Download "/private/data.csv" "C:\Temp\data.csv" "dlResult"
FTP Disconnect
KEYCHECK
  KEYCHAIN Success OR
    KEY "<dlResult>" EqualTo "OK"
  KEYCHAIN Failure OR
    KEY "<ERROR>" Contains "530"

Browser Action Blocks

Control a Selenium WebDriver instance for browser automation. Requires WebDriver configured in Settings → Selenium.

Navigate

Open a URL in the managed browser.

NAVIGATE "https://example.com/login" TIMEOUT:10000

BrowserAction

Perform browser-level actions (not tied to a specific element).

ActionDescription
SendKeysSend keyboard input. Special keys: <ENTER>, <TAB>, <BACKSPACE>, <ESC>. Chain with ||: <TAB>||Hello||<ENTER>
TakeScreenshotCapture browser screenshot into a variable
RefreshReload the current page
BackNavigate back in history
ForwardNavigate forward in history
SwitchToFrameSwitch WebDriver context to an iframe
SwitchToDefaultContentReturn to the main page context

ElementAction

Interact with a specific DOM element found by a locator.

LocatorExample value
idusername
classbtn-login
nameemail
tagbutton
selector#login-form input[type=password]
xpath//button[contains(text(),'Sign in')]

Actions per element: Click, ClearAndType, Type, GetText, GetAttribute, Submit, WaitForElement.

ExecuteJS

Run arbitrary JavaScript in the browser context. Variable values are substituted before execution. The return value is captured into the output variable.

EXECUTEJS "return document.querySelector('#token').value;" -> "csrfToken"

Debugger

Step through config execution interactively. Four tabs:

  • Data — current BotData variable values
  • Log — execution log with timestamps
  • HTML View — rendered source of last HTTP/browser response
  • Notepad — scratch pad for testing regex / LR patterns
